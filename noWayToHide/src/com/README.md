# `com/`

This directory is the first segment of the Java package namespace
`com.lastma`. In Java, the directory hierarchy under a source root conventionally
matches the dot-separated package name, so classes in the child package are
declared in `com.lastma`.

This directory is a namespace container, not an architectural layer. Put
application classes in the project package below it; do not place classes
directly in this namespace level. See [`lastma/`](lastma/README.md).
